## 🚀 Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/joaohgoncalves/portfolio.git
```

2. Acesse a pasta do projeto:
```bash
cd portfolio
```

3. Instale as dependências:
```bash
npm install
```

4. Execute o projeto:
```bash
npm run dev
```
